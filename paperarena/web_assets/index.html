Models & API

The default setup uses Gemini Flash Lite for retrieval and scoring, and Gemini Flash for Expert ranking. You can change every model and provider.

Retrieval settings & output

Top 5 mode reviews up to 60 shortlisted papers and makes five fixed full-text attempts. Missing full text retains abstract evidence, without replacements.

API keys stay in memory for this local session and are not saved to browser storage or result files. Starting retrieval calls the selected APIs.
