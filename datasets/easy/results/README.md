# Historical results

ChatGPT and Gemini TXT files preserve the supplied October 2026 browser Deep Research responses byte for byte. The adopted ChatGPT HARD source is the reviewed NEW report.

`idea2prior_top5.txt` is a readable export of the selected ten historical pipeline outputs. `idea2prior_results.json` retains their rankings, durations, API-reported usage, and original completion states. `idea2prior_expert/` contains the original Expert result JSON for each selected run.

Results are for post-run inspection and evaluation only. Runtime retrieval never reads this directory. Bibliographic errors or uncertain identities in a model response remain part of that response. Raw request logs, credentials, private endpoints, and downloaded PDFs remain outside the public dataset.

The summary in the project README follows the agreed historical reporting convention. See [benchmark accounting](../../../docs/BENCHMARK_RESULTS.md) for metric denominators. Idea2Prior license terms do not relicense third-party papers or provider content.
